# 🎤 Mic Booster

Веб-приложение для усиления громкости микрофона прямо в браузере.

## ✨ Возможности

- 🔊 Усиление микрофона до **20x** в реальном времени
- 📊 Визуализация звукового спектра
- 🎧 Мониторинг (слышать себя через наушники)
- ⏺ Запись усиленного звука в файл `.webm`
- 📱 Работает на мобильных устройствах

## 🚀 Использование

1. Откройте приложение по ссылке: **[ваш-username.github.io/mic-booster](https://ваш-username.github.io/mic-booster)**
2. Нажмите **«Запустить»** и разрешите доступ к микрофону
3. Регулируйте усиление ползунком
4. Для записи нажмите **«Запись»**, затем **«Стоп запись»** — файл скачается автоматически

## 💡 Как использовать с Discord

Браузер не может заменить системный микрофон напрямую, но есть обходной путь:

1. Установите **[VB-Audio Virtual Cable](https://vb-audio.com/Cable/)**
2. В Windows установите «CABLE Input» устройством воспроизведения по умолчанию
3. В приложении включите **мониторинг** (наденьте наушники!)
4. В Discord выберите микрофоном **«CABLE Output»**

## 🛠 Технологии

- **Web Audio API** — обработка звука
- **MediaRecorder API** — запись
- **Canvas API** — визуализация
